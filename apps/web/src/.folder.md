# Folder: apps/web/src/

> Trigger: When this folder's structure/responsibilities/file list changes, update this document.
> 触发条件：当本文件夹的结构/职责/文件列表变化时，更新此文档。

Web application source code: routes, components, services, hooks, and types.
Web 应用源代码：路由、组件、服务、钩子和类型定义。
Boundary: Entry point is main.tsx; routes handle page logic; services handle API.
边界：入口为 main.tsx；routes 处理页面逻辑；services 处理 API 调用。
Invariant: Components are pure UI; business logic lives in hooks and services.
不变量：组件是纯 UI；业务逻辑在 hooks 和 services 中。

## Files

- `main.tsx`: Application entry point, initializes React and Router / 应用入口，初始化 React 和 Router
- `App.tsx`: Root component with providers / 根组件，包含 providers
- `App.css`: Global application styles / 全局应用样式
- `index.css`: Base CSS including Tailwind / 基础 CSS（含 Tailwind）
- `routeTree.gen.ts`: Auto-generated route tree by TanStack Router / TanStack Router 自动生成的路由树
- `routes/`: File-based route definitions / 基于文件的路由定义
- `components/`: React UI components / React UI 组件
- `services/`: API service functions / API 服务函数
- `hooks/`: Custom React hooks / 自定义 React 钩子
- `types/`: TypeScript type definitions / TypeScript 类型定义
- `lib/`: Utility functions / 工具函数
- `assets/`: Static assets (images, icons) / 静态资源（图片、图标）
