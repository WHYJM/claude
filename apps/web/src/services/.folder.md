API service functions for gateway communication.
与 gateway 通信的 API 服务函数。
Boundary: Abstracts HTTP calls; returns typed responses; handles errors.
边界：封装 HTTP 调用；返回类型化响应；处理错误。
Invariant: All services call gateway endpoints; no direct backend service calls.
不变量：所有服务调用 gateway 端点；不直接调用后端服务。

## Files

- `authService.ts`: Authentication API (login, logout, session) / 认证 API（登录、登出、会话）
- `recipeService.ts`: Recipe CRUD operations / 食谱 CRUD 操作
- `projectService.ts`: Project management API / 项目管理 API
- `fridgeService.ts`: Fridge inventory API / 冰箱库存 API
- `aiService.ts`: AI recommendation API / AI 推荐 API
- `collaborationService.ts`: Real-time collaboration API / 实时协作 API
- `settingsService.ts`: User settings API / 用户设置 API
