# Folder: apps/web/src/routes/

> Trigger: When this folder's structure/responsibilities/file list changes, update this document.
> 触发条件：当本文件夹的结构/职责/文件列表变化时，更新此文档。

File-based routing using TanStack Router convention.
基于文件系统的路由，使用 TanStack Router 约定。
Boundary: Each file exports a route component; services handle data fetching.
边界：每个文件导出路由组件；services 处理数据获取。
Invariant: Route files match URL paths; dynamic params use $paramName syntax.
不变量：路由文件匹配 URL 路径；动态参数使用 $paramName 语法。

## Files

- `__root.tsx`: Root layout wrapping all routes / 根布局，包裹所有路由
- `index.tsx`: Dashboard/home page (/) / 首页仪表盘
- `login.tsx`: Login page (/login) / 登录页面
- `settings.tsx`: Settings page (/settings) / 设置页面
- `project.$projectId.tsx`: Project detail page (/project/:projectId) / 项目详情页
- `project.$projectId.recipe.$recipeId.tsx`: Recipe view (/project/:projectId/recipe/:recipeId) / 食谱查看页
- `project.$projectId.edit.$recipeId.tsx`: Recipe edit (/project/:projectId/edit/:recipeId) / 食谱编辑页
