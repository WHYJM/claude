# Folder: apps/web/

> Trigger: When this folder's structure/responsibilities/file list changes, update this document.
> 触发条件：当本文件夹的结构/职责/文件列表变化时，更新此文档。

Main web application built with Vite + React 19 + TanStack Router/Query.
主 Web 应用，使用 Vite + React 19 + TanStack Router/Query 构建。
Boundary: Consumes packages/* for types/UI; calls gateway API via services/.
边界：消费 packages/* 的类型/UI；通过 services/ 调用 gateway API。
Invariant: All routes are file-based via TanStack Router in src/routes/.
不变量：所有路由通过 TanStack Router 基于文件系统定义在 src/routes/。

## Files

- `src/`: Source code directory / 源代码目录
- `public/`: Static assets served directly / 直接服务的静态资源
- `index.html`: HTML entry point for Vite / Vite HTML 入口
- `vite.config.ts`: Vite build configuration / Vite 构建配置
- `package.json`: Package dependencies and scripts / 包依赖和脚本
- `tsconfig.json`: TypeScript root configuration / TypeScript 根配置
- `tsconfig.app.json`: App-specific TypeScript config / 应用 TypeScript 配置
- `tsconfig.node.json`: Node.js TypeScript config for Vite / Node.js TypeScript 配置
- `tsr.config.json`: TanStack Router configuration / TanStack Router 配置
- `eslint.config.js`: ESLint configuration / ESLint 配置
- `components.json`: Shadcn/ui component configuration / Shadcn/ui 组件配置
