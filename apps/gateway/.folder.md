BFF API Gateway using Hono framework with Better Auth authentication.
使用 Hono 框架的 BFF API 网关，集成 Better Auth 认证。
Boundary: Receives requests from frontend; routes to backend services.
边界：接收前端请求；路由到后端服务。
Invariant: All frontend requests go through gateway; direct backend access prohibited.
不变量：所有前端请求经过网关；禁止直接访问后端。

- `package.json`: Package dependencies and scripts / 包依赖和脚本
- `tsconfig.json`: TypeScript configuration / TypeScript 配置
- `drizzle.config.ts`: Drizzle ORM configuration / Drizzle ORM 配置
