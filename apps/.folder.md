# Folder: apps/

> Trigger: When this folder's structure/responsibilities/file list changes, update this document.
> 触发条件：当本文件夹的结构/职责/文件列表变化时，更新此文档。

Frontend applications managed by Turborepo, serving as user-facing layer.
所有前端应用由 Turborepo 管理，作为用户交互层。
Boundary: Consumes packages/*, communicates with backend via gateway.
边界：消费 packages/*，通过 gateway 与后端服务通信。
Invariant: All apps share common types from packages/shared-types.
不变量：所有应用共享 packages/shared-types 中的类型定义。

## Files

- `web/`: Main web application - React 19 + Vite + TanStack Router / 主 Web 应用
- `mobile/`: Mobile application - Expo + React Native / 移动端应用
- `gateway/`: BFF API Gateway - Hono + Better Auth / BFF API 网关及认证服务
